# INPUT DESIGN

| **Input Field**       | **UI Label**       | **Type / Unit**    | **Required / Optional**              | **Valid Range**                                                                                  | **Default** | **Error Message / Validation**                                               |
|------------------------|--------------------|--------------------|--------------------------------------|--------------------------------------------------------------------------------------------------|-------------|--------------------------------------------------------------------------------|
| Choose role            | Role Selection     | Card Selection     | Required                             | 1 of 3 roles: Information Hunter, Investor, Arbitrageur                                          | None        | “Please select a role to start.”                                             |
| JPY Borrowing          | Borrow JPY         | Buttons / %        | Required (Round 1)<br>Optional (Rounds 2–4) | 25%, 50%, 75%, 100% (Round 1)<br>Additional 0% option (Rounds 2–4) | None | Percentage options exceeding the remaining borrowing capacity are disabled. |
| Buying Assets          | Buy US Assets      | Number / Units     | Required (Round 1)<br>Optional (Rounds 2–4) | From 0 to the maximum number of units affordable with available free cash | 0 | “Insufficient Free Cash.” |
| Selling Assets         | Sell US Assets     | Number / Units     | Optional                             | From 0 to current holdings                                                                        | 0           | “You only own X units.”                                                       |
| Bank Deposit           | Deposit Amount     | Number / USD ($)   | Optional                             | From $0 to the available Free Cash balance                                                        | $0          | “Insufficient Free Cash.”                                                     |
| Bank Withdrawal        | Withdraw Amount    | Number / USD ($)   | Optional                             | From $0 to the current US Cash balance deposited in the bank                                      | $0          | “Insufficient US Cash.”                                                        |
| JPY Loan Repayment     | Select Loan to Pay | Checkbox           | Optional (Rounds 1–4)                | Select the loans to repay                                                                        | Unchecked   | “Insufficient Cash. Sell assets first.”                                      |
| Buy Information        | Buy Information    | Button             | Optional                             | Information can be purchased at the price determined by each role (maximum 1 purchase per round) | None | “Purchase rejected.” |
